URL Relativa com Base

Exemplo pedido no slide:

<base href="http://www.meusite.com.br/">
<img src="imagens/cabecalho.png" alt="Meu Site">
<a href="paginas/contato.html">Contato</a>

Isso faria o navegador interpretar os caminhos relativos a partir do dominio informado em <base>.
