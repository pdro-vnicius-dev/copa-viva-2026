# Copa Viva 2026

Site estático com tema da Copa do Mundo, desenvolvido para atividade escolar usando apenas HTML e CSS.

## Recursos

- Layout responsivo com Flexbox
- Menu adaptável para celular sem JavaScript
- Banner de abertura com imagem temática
- Galeria de seleções participantes
- Cards de jogadores em destaque
- Histórico das Copas
- Tabela fictícia de jogos
- Efeitos com `transition`, `transform` e `animation`
- Fotos reais usadas no banner e na galeria

## Como abrir

Abra o arquivo `index.html` no navegador.

## Tecnologias

- HTML5
- CSS3

Nenhum JavaScript foi utilizado.
